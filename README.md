# Go to the Moon

地球からロケットを発射して月へ届ける、操作は「発射ボタンを押すタイミング」だけのブラウザゲームです。

▶️ Play: https://sazanamix.github.io/go-to-the-moon/

## 遊び方

地球は自転しており、ロケットは地球の外周にくっついたまま自転と一緒に回転しています。
**「発射」ボタンを押した瞬間の接線方向**にロケットが打ち出されます。速度は常に一定なので、
ハンマー投げの的当てのように、**押すタイミング(＝射出角度)だけ**で月を狙います。

打ち出した後は地球と月の重力に従って軌道を飛ぶだけで、追加の操作はありません。
月の重力圏に十分入れば到達、地球に落ちたり彼方へ飛び去ったりすれば失敗です。
明らかに外したとわかったら「あきらめてリトライ」でいつでも即座に打ち直せます。

到達に成功すると、月に届くまでの飛行時間が短い順にこの端末内のランキング(TOP10)に記録されます
(`localStorage`のみに保存するローカル記録で、サーバーは持たないため他の端末とは共有されません)。

## 物理モデル

できるだけ実際の値・実際の計算で動かしています。

- **地球の自転**: 実際の恒星日(23時間56分)で発射台が回転し、ロケットの初期方向と接線速度を決めます。
- **地球の公転**: 地球（＋その上のロケット）は太陽の重力に対して自由落下している慣性系とみなせるため、
  月までの短時間の遷移軌道の計算では、地球中心の慣性座標系を使い公転そのものは陽には計算していません
  (実際のアポロ計画の遷移軌道計算も地球中心慣性系を用いています)。
- **月の軌道**: 離心率 0.0549 の本物の楕円軌道。ケプラー方程式 `M = E - e sinE` を毎フレーム数値的に解いて、
  実際の公転周期(27.321661日)どおりに位置を計算しています(円軌道ではありません)。
- **重力**: 発射後のロケットには地球・月それぞれの重力パラメータ(GM)による重力が働き、
  4次のルンゲ-クッタ法(RK4)で数値積分しています。月に近づけば月の重力に引かれる「重力捕獲」も
  自然に再現されます。
- **ロケットの初速**: 地球の自転による接線速度(約465 m/s)＋ロケット自身の固定Δv(約10.6 km/s)を
  合成した、常に一定の速さ(約11.1 km/s)。方向だけが発射タイミングで変わります。

### 簡略化した点(正直に書いておきます)

- 月の軌道傾斜(黄道に対し約5.1°)や地球の地軸傾斜は無視し、平面(2D)の地球-月系のみを扱っています。
- 太陽や他の惑星の重力は計算していません(地球中心慣性系での近似が妥当なため)。
- 月の近地点方向の長期的な歳差(公転周期約8.85年)は無視し、固定方向としています。
- 「月に到達」の判定は月の物理的な表面ではなく、月の重力に十分捕まったとみなせる半径
  (月中心から約1万km)としています。
- そのままでは月まで数日かかるため、シミュレーション内時間を約9000倍速で進めています。
  すべての天体・軌道に同じ倍速をかけているので、周期どうしの比率(自転:公転など)は実際の値のままです。
